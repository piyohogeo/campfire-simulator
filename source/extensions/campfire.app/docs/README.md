# Campfire App `[campfire.app]`

Campfire Simulatorのシーン、Flow火炎、動的薪、操作UI、ヘッドレス検証を提供するPython Kit Extensionです。

Phase 5では木材セルから断面支持率を求め、事前分割した薪のFixedJointを支持喪失時に解除します。残存質量・コライダー更新、PhysX崩落、通気回復後の再燃を同じヘッドレス実行で検証できます。

Phase 6AではNISTIR 7094の5層合板データを固定参照し、既存円柱セルへの等価クーポン写像で着火時刻と平均質量減少速度を比較します。決定的な候補探索、USD棒グラフ、SVGレポート、CSV・JSON出力を提供します。これは校正基盤であり、独立した合板妥当性確認ではありません。

Phase 6Bでは候補選択に使用しない同報告書のOSB平均値へ、合板で選んだ係数を再調整なしで適用します。別材料への外挿ストレステストであり、合板内検証やOSB固有物性モデルではありません。

Phase 6CではAppendix Aの合板反復試験を固定分割し、各熱流束のSAMP.1/2だけで候補を選び、未使用のSAMP.3へ再調整なしで適用します。同一材料・同一熱流束での再現性テストであり、新しい曝露条件への予測検証ではありません。

Phase 6Dでは等価円柱を、公称12.7 mm、0.1 m角、5等厚層の平板試験片へ置き換えます。観測初期質量から有効乾燥密度を求め、加熱面から裏面への層間熱伝導を解きます。厚さの適用、等厚層、交互木目は明示した仮定で、接着層とArrhenius反応は未実装です。

Phase 6Eでは一次Arrhenius式`k(T)=A exp(-E/RT)`を導入します。Thurner–Mannのガス・タール・炭経路の公開A/E組をSI単位へ変換し、A倍率と吸収率を含む48候補をSAMP.1/2で選定します。各経路を単一の見かけ反応候補として使う簡略化で、元論文の3経路同時計算ではありません。

Phase 6Fでは同じ未反応木材に対してガス・タール・チャー経路を競合させ、`k_i / Σk`で生成物を分配します。相対A/Eは一次資料へ固定し、4共通倍率×4吸収率の16候補だけをSAMP.1/2で選定します。ガス・タール放出量、一次チャー生成量と累積収率を質量保存勘定の内訳として出力します。
