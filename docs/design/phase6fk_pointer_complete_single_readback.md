Python identity and `numpy.shares_memory()` are useful evidence, but neither substitutes for positive pointer values proving that the observed source and converted buffers share the same address.

Phase 6FK starts a fresh balanced population. A performs no readback, B performs one public NanoVDB readback and releases all aliases, and C performs one public readback plus exactly one `numpy.asarray(fuel)` before ordered alias release. The fixed order is `ABC / BCA / CAB`, with three representative cases per condition. Only a pre-operation startup prerequisite failure may consume one of two replacement launches; the first pointer, operation, lifecycle, resource, fatal, diagnostic, or cleanup failure stops the population without retry.

For every C case, `fuel_source` and `fuel_array` must contain positive built-in integer pointers read from the public `__array_interface__.data[0]`. Missing, zero, negative, non-integer, or unequal pointers are nonreplaceable operation failures. Raw markers and the final report both preserve the pointers.
